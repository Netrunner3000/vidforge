# Background music

Drop royalty-free `.mp3` / `.m4a` / `.wav` beds in this folder. `vidforge` picks one
at random per video, loops it to length, and (with `music.duck: true`) ducks it
under the narration with a sidechain compressor.

Audio files here are gitignored — keep the licences you rely on somewhere you
can find them again.

Sources that are safe for monetised YouTube (check each licence yourself):

- YouTube Audio Library (`studio.youtube.com` → Audio Library) — free, cleared for monetisation
- Kevin MacLeod / incompetech.com — CC-BY, requires attribution in the description
- Free Music Archive — per-track licences, read before using

If this folder is empty, videos render fine with narration only.
